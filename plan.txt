# Engineering Plan: Real-Time Ear Tracking & 3D Earring Try-On Web App

## Project Objective
Build a Vite + vanilla JS real-time web application that captures a webcam feed, processes frames locally using a custom-trained YOLOv8-pose ONNX model to find the precise anatomical earlobe, and renders a 3D earring model (.glb/.gltf) using Three.js at the decoded keypoint coordinates.

---

## System Architecture & Stack
- **AI Model:** Custom YOLOv8-nano-pose (Input: 640x640x3 RGB, Output: Keypoints tracking earlobe anatomy).
- **Inference Engine:** `onnxruntime-web` (WebGPU / WebGL / WASM execution providers).
- **3D Rendering:** `three.js` (transparent WebGLRenderer; MVP screen-space orthographic attach).
- **Bundler:** Vite + ES modules.
- **Privacy:** All inference local in browser; no frame upload.

```text
Dataset -> train.py -> best.onnx -> onnxruntime-web -> decoder -> Three.js overlay
```

## Strict Guardrails & Engineering Directives
1. **Performance:** Target >30 FPS; reuse pre-allocated TypedArrays; throttle ONNX in `inference-loop.js`.
2. **Coordinate sync:** Video mirrored (`scaleX(-1)`); map X in `mapToScreen`.
3. **WASM handling:** CDN fallback for `ort.env.wasm.wasmPaths` in `onnx-engine.js`.
4. **Model format:** ONNX for weights; WASM is onnxruntime-web runtime only (see README).
